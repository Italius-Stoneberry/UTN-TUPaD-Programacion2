## Requisitos y Ejecución

El sistema requiere **Python 3.12 o superior**.

Para iniciar la aplicación interactiva por consola, tienen que abrir la terminal y ejecute el siguiente comando en la raíz del proyecto o bien directamente desde Vs Code ejecutar el mismo archivo:

```
python main.py

```
